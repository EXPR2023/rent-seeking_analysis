日常启动

在项目根目录：

cd T:\rent-seeking_analysis
cd docker
docker compose --env-file ../.env up -d
docker compose ps
cd ..
然后开一个新终端启动后端：

cd T:\rent-seeking_analysis\backend
$env:MYSQL_PORT="3307"
..\.tools\apache-maven-3.9.9\bin\mvn.cmd spring-boot:run "-Dspring-boot.run.profiles=local"
再开一个新终端启动前端：

cd T:\rent-seeking_analysis\frontend
npm run dev
访问：

http://localhost:5173
